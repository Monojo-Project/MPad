# MPad
## Monojo Pad, un editor de texto gráfico hiper optimizado.
### ¡Tan solo 3 MB de RAM!

Dependencias para compilar en Debian/Ubuntu/LyndsOS:
```
sudo apt install libfltk1.3-dev build-essential libpng-dev
```

Depués escribes
```
make
```
en el directorio del Makefile y ya se compila.


Dependencias para ejecutar el binario en Debian/Ubuntu/LyndsOS:
```
sudo apt install libfltk1.3
```

¿Qué es libfltk1.3?
FLTK (Fast Light Toolkit) es una librería gráfica súper ligera y optimizada, aunque se vea algo antigua. Así, MPad llega a consumir tan poco.
